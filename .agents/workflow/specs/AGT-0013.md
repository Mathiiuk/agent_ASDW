# Specification — AGT-0013

## 1. Objetivo
Que la IA no tenga que recordar el flujo: una sola consulta le dice la próxima acción.

## 2. Problema actual
La IA debía saber qué tool invocar según el estado del plan, y no había salida JSON para hooks o scripts.

## 3. Resultado esperado
`getNextStep()` devuelve `{ action, done, task, artifacts, diagnosis, instructions, tool, cli, progress }`. Está expuesto como tool MCP `next_step`, como `agt next [--json]` y como `agt phase:status --json`.

## 4. Alcance
### Incluido
- Acciones `IMPLEMENT_FEATURE`, `FIX_BUG`, `RUN_HEALTHCHECK`, `FIX_HOTFIX`, `BLOCKED`, `DONE` y `NO_ACTIVE_PLAN`.
### No incluido
- Ejecutar la acción automáticamente: la ejecuta la IA.

## 5. Criterios de aceptación
- [x] AC-01: El ciclo completo feat → fix → feat → healthcheck → hotfix → done devuelve la acción correcta en cada paso.
- [x] AC-02: `done` es `true` solo cuando no queda trabajo para la IA.
- [x] AC-03: La tool MCP y la CLI devuelven lo mismo.
