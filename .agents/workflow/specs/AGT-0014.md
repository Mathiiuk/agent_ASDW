# Specification — AGT-0014

## 1. Objetivo
Garantizar que el agente llegue al final del plan sin detenerse antes y sin bucles infinitos.

## 2. Problema actual
La IA podía terminar su turno con fases pendientes, o insistir indefinidamente con un bug que necesita a un humano.

## 3. Resultado esperado
- **Límite de intentos:** con `max_attempts` checks fallidos consecutivos, el plan pasa a `BLOCKED` y se reanuda con `phase:resume`.
- **`agt hook:stop`:** el hook Stop de Claude Code bloquea el cierre mientras haya trabajo pendiente.
- **Instalación:** `agt hook:install` y `agt init` registran el hook en `.claude/settings.json`.

## 4. Alcance
### Incluido
- Salvaguarda `--max-idle`: tras N avisos sin progreso, se permite detenerse.
- El hook nunca bloquea ante errores internos.
### No incluido
- Hooks para otros IDEs (Cursor, Windsurf).

## 5. Criterios de aceptación
- [x] AC-01: N fallos consecutivos bloquean el plan; un check en verde reinicia la racha.
- [x] AC-02: El hook bloquea con trabajo pendiente y libera con el plan `COMPLETED`/`BLOCKED`, sin plan activo, o sin progreso.
- [x] AC-03: La instalación es idempotente y conserva la configuración existente.
