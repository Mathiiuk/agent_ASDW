# Specification — AGT-0012

## 1. Objetivo
Permitir que la CLI y el servidor MCP operen sobre un proyecto distinto del directorio desde el que se lanzan.

## 2. Problema actual
Todas las tools usaban `process.cwd()`. Clientes como Claude Desktop lanzan el servidor desde otro directorio, así que las tools leían y escribían en el lugar equivocado.

## 3. Resultado esperado
Raíz resuelta con prioridad `projectRoot` (argumento de la tool) > `AGT_PROJECT_ROOT` > `cwd`. En la CLI, `--root <dir>`.

## 4. Alcance
### Incluido
- `src/project-root.js` (`resolveProjectRoot`), `callTool()` en el MCP, `projectRoot` en todas las tools y flag global `--root`.
### No incluido
- Operar sobre varios proyectos en una misma llamada.

## 5. Criterios de aceptación
- [x] AC-01: Toda tool MCP acepta `projectRoot` y lo respeta.
- [x] AC-02: `AGT_PROJECT_ROOT` se usa cuando no hay argumento.
- [x] AC-03: `agt --root <dir>` opera sobre ese directorio; una ruta inexistente da un error claro.
