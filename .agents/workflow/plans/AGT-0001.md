# Plan de Implementación - AGT-0001

## 1. Módulos y Arquitectura

```text
bin/
└── agente-dev.js          # Punto de entrada ejecutable CLI
src/
├── git.js                 # Integración con Git (ramas, slug, status, checkout)
├── task-manager.js        # Generación y manipulación de artefactos de tareas
├── validator.js           # Validación de manifiestos y ejecución de quality gates
└── index.js               # Exportaciones principales de la librería
tests/
├── git.test.js            # Pruebas unitarias para el módulo Git
├── task-manager.test.js   # Pruebas unitarias para TaskManager
└── validator.test.js      # Pruebas unitarias para Validator
```

## 2. Plan de Trabajo Paso a Paso
1. **Configuración de `package.json`**: Añadir scripts, `"bin"`, `"type": "module"` y dependencias (`commander`, `js-yaml`, `chalk`, `vitest`).
2. **Implementación de `src/git.js`**: Funciones para sanitizar slugs, resolver nombres de ramas, obtener rama actual, verificar estado de Git y cambiar de rama.
3. **Implementación de `src/task-manager.js`**: Funciones para instanciar manifiestos YAML y plantillas Markdown reemplazando placeholders (`<TASK-ID>`, `<TITULO>`, etc.).
4. **Implementación de `src/validator.js`**: Funciones para validar campos requeridos de manifiestos YAML y disparar Quality Gates.
5. **Implementación de `bin/agente-dev.js`**: Comandos `task:new`, `task:branch`, `task:verify`, `task:list` con interfaz gráfica en consola.
6. **Desarrollo de Pruebas Unitarias**: Escribir suites completas en `tests/` con Vitest.
7. **Quality Gates & Verificación**: Correr `npx vitest run`, enlazar con `npm link` y probar manualmente.
